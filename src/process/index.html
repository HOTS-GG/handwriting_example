용어 정리

순전파
입력값에 가중치를 곱해 더하고(가중합) 활성화 함수를 거쳐 출력까지 계산하는 과정
오차(손실)
예측값과 정답의 차이. ½(예측−정답)²로 계산해요
역전파
출력층의 오차를 입력층 방향으로 거꾸로 전달하며 각 가중치가 오차에 얼마나 책임이 있는지(기울기) 계산하는 과정
가중치 수정
새 가중치 = 가중치 − 학습률 × 기울기 (경사 하강법)
에포크
학습 데이터 전체를 한 번 다 사용해 학습한 횟수
