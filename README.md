# 딥러닝 수업 실험실 (웹페이지 3종)

교과서 Ⅱ-03 「인공신경망과 딥러닝」 수업용 웹페이지입니다. **각 페이지는 HTML 파일 하나**로 동작하며,
서버나 인터넷 없이 학생 기기(PC·태블릿·스마트폰)의 브라우저에서 직접 계산합니다.
파일을 메신저·USB·클래스룸 등으로 나눠 주고 더블클릭하면 됩니다.

| 파일 | 내용 | 크기 |
|---|---|---|
| `index.html` | **손글씨 숫자 인식 실험실**: 그 자리에서 숫자를 쓰면 CNN이 실시간으로 인식하고 층별 과정을 보여 줌 | 3.2MB |
| `deep-learning-process.html` | **딥러닝 학습 과정 실험실**: 신경망이 학습하는 모습(순전파 → 오차 → 역전파 → 가중치 수정)을 보여 줌 | 0.1MB 미만 |
| `image-classifier.html` | **이미지 분류 실험실**: 사진·웹캠 이미지를 1000가지 중 하나로 분류하고 층별 과정과 판단 근거를 보여 줌 | 7.3MB |

모든 화면은 **왼쪽: 입력 / 가운데: 과정 / 오른쪽: 결과**로 구성되어 있습니다.

---

## 1. 손글씨 숫자 인식 실험실 (`index.html`)

- **왼쪽**: 캔버스에 직접 쓰기, 지우기/되돌리기, 펜 굵기, 쓰는 과정 다시보기, 획마다 예측 변화, 내 실험 기록(정확도)
- **가운데**: ① 전처리(자르기 → 20×20 → 28×28, 픽셀값 0~255) ② 합성곱층1 ③ 풀링층1 ④ 합성곱층2 ⑤ 풀링층2 ⑥ 평탄화 ⑦ 완전 연결층 ⑧ 출력층. 특징 지도를 누르면 '필터 ⊛ 입력 = 특징 지도'로 확대
- **오른쪽**: 예측 숫자와 확신도, 0~9 확률, **k-최근접 이웃(k=5)과 비교**
- 모델: 교과서 딥러닝 실습과 같은 구조 `Conv2D(32)→MaxPool→Conv2D(64)→MaxPool→Flatten→Dense(128)→Dense(10)`, MNIST 테스트 정확도 **99.59%**

## 2. 딥러닝 학습 과정 실험실 (`deep-learning-process.html`)

교과서 116~119쪽 텐서플로 플레이그라운드 실습을 한국어로 재현했습니다.

- **왼쪽**: 데이터 4종(원형·XOR·가우시안·나선), 잡음, **교과서 실습 따라하기 버튼**(단층/다층 퍼셉트론 × 단순/복잡한 분류, XOR 도전)
- **가운데**: 신경망 그림. 은닉층·뉴런 수 조절, 입력 특성(X₁, X₂, X₁², X₂², X₁X₂, sin) 켜고 끄기, 각 뉴런이 평면 어디에서 켜지는지, 가중치 색·굵기
  - **🔍 데이터 하나로 학습 한 단계 따라가기**: 점 하나를 골라 ① 순전파(가중합·활성화 계산식) ② 오차 계산 ③ 역전파(δ) ④ 가중치 수정(이전 → 새 값, 오차 감소)을 실제 숫자와 애니메이션으로 확인
- **오른쪽**: 결정 경계, 학습/시험 오차 그래프, 시험 정확도
- 위쪽: 학습 ▶/⏸, 1 에포크씩, 학습률, 학습 속도, 활성화 함수(Tanh·ReLU·Sigmoid·Linear)

## 3. 이미지 분류 실험실 (`image-classifier.html`)

- **왼쪽**: 사진 고르기 / 끌어다 놓기 / Ctrl+V 붙여넣기 / **웹캠 실시간 인식** / 예시 사진 6장
- **가운데**: ① 입력(RGB 3채널) ②~⑦ 합성곱 층별 특징 지도(얕은 층: 선·색 → 깊은 층: 부분·물체) ⑧ 전역 평균 풀링 ⑨ 1000가지 확률
- **오른쪽**: 1등 종류(한국어·영어)와 확신도, 상위 5개, **어디를 보고 판단했는지 히트맵(CAM)**, 1000가지 종류 목록 검색
- 모델: Google **MobileNet v1** (ImageNet 1000종, Apache 2.0)을 8비트로 압축해 내장, 실행은 TensorFlow.js(Apache 2.0)
- 참고: 웹캠은 브라우저에서 카메라 권한을 허용해야 합니다. 이미지넷에는 '사람' 종류가 없습니다.

## 수업 활동 아이디어

1. (손글씨) 4의 첫 획만 썼을 때 무엇으로 인식할까? 일부러 헷갈리게 써서 인공지능 속여 보기
2. (손글씨) 「내 실험 기록」으로 딥러닝과 k-최근접 이웃의 정확도 비교해 활동지 작성
3. (학습 과정) 단층 퍼셉트론이 나선·XOR을 못 푸는 이유와, 은닉층·특성을 늘리면 풀리는 이유 토의
4. (학습 과정) 학습률을 0.001 / 0.03 / 3으로 바꿔 '한 단계 따라가기'의 가중치 변화량 비교
5. (이미지 분류) 같은 물건을 각도·밝기·배경을 바꿔 찍어 보고 결과가 어떻게 달라지는지 관찰
6. (이미지 분류) 히트맵을 보고 인공지능이 물체 자체가 아닌 배경을 보고 판단한 사례 찾기

## 개발자용

```
src/handwriting/  src/process/  src/classifier/   ← 원본 소스 (수정은 여기서)
tools/build.py            src/ 를 합쳐 단일 HTML 3개 생성
tools/train.py            손글씨 CNN 학습 (pip install torch numpy, mnist.npz 필요, CPU 약 3분)
tools/verify.js           손글씨 CNN의 JS 계산이 파이토치와 같은지 확인
tools/pack_mobilenet.py   MobileNet 내려받아 8비트 압축 + 한국어 분류 이름(tools/imagenet_ko.tsv) 포함
```

수정 후에는 `python tools/build.py` 를 실행하면 루트의 HTML 파일들이 다시 만들어집니다.
