# 손글씨 숫자 인식 실험실

학생이 그 자리에서 숫자를 손으로 쓰면, 합성곱 신경망(CNN)이 **각 학생의 브라우저 안에서 실시간으로** 계산하며
층별 처리 과정과 인식 결과를 보여 주는 수업용 웹페이지입니다.
(교과서 Ⅱ-03 「인공신경망과 딥러닝」 · 딥러닝 실습의 CNN 구조와 동일)

| 왼쪽: 손글씨 쓰기 | 가운데: 딥러닝이 생각하는 과정 | 오른쪽: 인식 결과 |
|---|---|---|
| 캔버스에 직접 쓰기, 지우기/되돌리기, 펜 굵기, **쓰는 과정 다시보기**, 획마다 예측 변화 기록, 내 실험 기록(정확도) | ① 전처리(자르기 → 20×20 → 28×28, 픽셀값 0~255) ② 합성곱층1 (32장) ③ 풀링층1 ④ 합성곱층2 (64장) ⑤ 풀링층2 ⑥ 평탄화(1600) ⑦ 완전 연결층(128) ⑧ 출력층(softmax) — 특징 지도를 누르면 필터⊛입력=특징 지도로 확대 | 예측 숫자와 확신도, 0~9 확률 막대, **k-최근접 이웃(k=5)과 비교**(가장 비슷한 학습 이미지 5장 표시) |

## 사용 방법

서버가 필요 없습니다. 모든 계산은 학생 기기(PC·태블릿·스마트폰)에서 이루어지고, 인터넷 연결도 필요 없습니다.

- **가장 간단한 방법:** 폴더를 내려받아 `index.html`을 더블클릭
- **학생들에게 링크로 배포:** 저장소 Settings → Pages → Branch 선택 후 저장하면 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다.

## 모델

```
Input(28,28,1) → Conv2D(32,3×3,relu) → MaxPool(2×2) → Conv2D(64,3×3,relu) → MaxPool(2×2)
→ Flatten → Dense(128,relu) → Dense(10,softmax)
```

- MNIST 6만 장으로 학습, 테스트 정확도 **99.59%**
- 손으로 쓴 글씨에 강하도록 회전·크기·위치·기울기·굵기를 바꿔 가며 학습(데이터 증강)
- 가중치는 `js/model-weights.js`, 순전파 계산은 라이브러리 없이 `js/model.js`에 직접 구현 (1회 계산 약 5ms)

### 다시 학습하려면 (선택)

```bash
pip install torch numpy
curl -O https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz
python tools/train.py mnist.npz   # CPU에서 약 3분 (GPU면 더 빠름)
node tools/verify.js              # JS 계산이 파이토치와 같은지 확인
```

## 수업 활동 아이디어

1. 숫자를 쓰는 도중 예측이 어떻게 바뀌는지 관찰하기 (예: 4의 첫 획만 쓰면 무엇으로 인식할까?)
2. 합성곱층 1의 특징 지도를 눌러 각 필터가 어떤 방향의 선에 반응하는지 찾아보기
3. 일부러 헷갈리게 써서 인공지능을 속여 보고, 왜 틀렸는지 확률 분포로 설명하기
4. 「내 실험 기록」으로 딥러닝과 k-최근접 이웃의 정확도를 비교해 활동지 작성하기
